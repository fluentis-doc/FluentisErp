Parametri se nalaze na putanji **Parametri > Kvalitet > Parametri umjeravanja instrumenata**.

Podaci iz ovog podešavanja koriste se za predlaganje informacija u modulima:
> *Merni instrumenti*;
> *Kalibracija instrumenata*.

#### Posebno dugme

**Sačuvaj**: omogućava čuvanje izmenjenih podataka.

#### Posebna polja

- **Odgovorno lice**: *zaposleni* koji se predlaže kao odgovorno lice prilikom kreiranja novog *mernog instrumenta*.
- **Odgovorna funkcija**: *funkcija u preduzeću* koja se predlaže kao odgovorna prilikom kreiranja novog *mernog instrumenta*.
- **Vrsta negativnog ishoda**: *vrsta ishoda* koja se predlaže u slučaju negativnog rezultata.
- **Vrsta pozitivnog ishoda**: *vrsta ishoda* koja se predlaže u slučaju pozitivnog rezultata.
- **Vrsta ručne kalibracije**: *vrsta kalibracije* koja se predlaže pri ručnom unosu *kalibracije instrumenata*.
- **Vrsta interne kalibracije**: *vrsta kalibracije* koja se predlaže pri planiranju *interne kalibracije instrumenata*.
- **Vrsta eksterne kalibracije**: *vrsta kalibracije* koja se predlaže pri planiranju *eksterne kalibracije instrumenata*.

Za sve funkcionalnosti obrazaca koje nisu detaljno opisane u ovom dokumentu pogledajte sledeću vezu: [Zajedničke funkcionalnosti, dugmad i polja](/docs/guide/common).
