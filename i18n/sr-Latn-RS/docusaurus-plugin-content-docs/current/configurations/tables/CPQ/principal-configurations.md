Otvaranjem ove tabele pristupa se interfejsu za pretragu prethodno kodifikovanih glavnih konfiguracija, što predstavlja polaznu tačku za kreiranje novih.

Otvaranjem konfiguracije prikazuju se podaci zaglavlja i tri donje kartice.

## Zaglavlje

Zaglavlje sadrži sledeća polja:

- **Tip konfiguracije**: ovde se navodi [tip](/docs/configurations/tables/CPQ/configuration-type) konfiguracije.
- **Šifra**: dodeljuje se jedinstvena šifra koja se može menjati.
- **Verzija**: konfiguraciji se dodeljuje broj verzije, počevši od 1.
- **Opis**: moguće je dodati slobodan opis.
- **Datum početka/kraja važenja**: moguće je odrediti vremenski raspon važenja konfiguracije.
