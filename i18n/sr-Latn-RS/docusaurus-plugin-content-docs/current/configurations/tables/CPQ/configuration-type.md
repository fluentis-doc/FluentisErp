---
title: Tipovi konfiguracije
sidebar_position: 1
---

U ovoj tabeli definišu se tipovi konfiguracija koji se mogu kreirati. Tipovi se definišu sledećim karakteristikama:

- **Šifra/Opis**: jedinstveni identifikatori tipa.
- **Napomena**: moguće je dodati slobodnu napomenu koja se odnosi na ove tipove konfiguracija.
- **Konfigurisani objekat**: u ovom polju navodi se poslovni objekat za koji je određeni tip konfiguracije važeći.
