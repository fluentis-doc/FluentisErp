title: Tip resursa
sidebar_position: 4

Ova tabela dostupna je putem **Tablice > Upravljanje projektima > Tip resursa** i sadrži tipove dostupnih resursa. Moguće je kreirati, pretraživati i brisati tipove. Definisani su pomoću **Šifre**, **Opisa** i **Tipa**, koji može biti Ljudski ili Materijalni.
