title: Period Types
sidebar_position: 5
---

The form allows you to enter periods for each year. For each period, you can set the necessary weeks or detailed sub-periods (e.g., days). The form contains two sections: the first with the periods and the second with the details of the various (types of) periods created by the user.

The table is also used for some functionalities (coming soon) related to Forecast, and therefore not all fields are currently used.

For companies that manage Controlling<!-- Controlling -->, if you want the budget to be correctly integrated with the controlling logic, it is necessary to define a **monthly<!-- mensile -->** period with the grid details referring to the individual months of the year (the flags Deletable<!-- Eliminabile -->, Used<!-- Usato -->, Default as well as the *Sequence<!-- Sequenza -->* field are not relevant for the Budget module).

There may also be different periodicities as long as they are consistent with the frequency used in the controlling<!-- controlling --> system (e.g., weekly<!-- settimanale -->).

Even if a complete controlling<!-- controlling --> system is not used (e.g., you want to use the Budgeting module simply for an accounting-type Budget), a rational configuration is recommended, such as monthly<!-- mensile --> (typical case) or weekly<!-- settimanale -->. Other periodicities may also be valid, such as quarterly<!-- trimestrale -->.
