This procedure can be used by companies that fully utilize the Controlling module<!-- modulo Controlling --> (and have the *Controlling management<!-- Gestione controlling -->* flag active in the company master data), as it allows you to populate the tables in the Budget Area<!-- Area di budget --> that were already used in previous major releases for budgeting purposes.

At the top, select the budget<!-- budget --> to use with the appropriate combo box; in the grid, you will see the *sub-budgets<!-- sotto-budget -->* of type ***cost center<!-- centro di costo -->***, the only ones that make sense to read in order to populate the budget areas<!-- aree di budget -->: at the bottom of the form, you will need to set the area<!-- area --> to assign and the ledger template to use.

The **Create off-balance budget records<!-- Creazione registrazioni extracontabili di budget -->** button will create the off-balance budget records<!-- Registrazioni extra contabili di budget --> that can be searched in the [**dedicated form**](/docs/controlling/budget/offbalance-records-search). The second button, **Create budget records history<!-- Creazione storico registrazioni di budget -->**, will directly populate the budget history<!-- storico di budget -->, which can also be viewed from the [**dedicated form**](/docs/controlling/budget/budgeting-records-search).

This second option allows you to directly populate the actual budget database<!-- base dati consuntiva di budget -->, so you can proceed directly with the reclassification comparison in order to analyze the variances between the Budget Area<!-- Area budget --> and the Actuals Area<!-- Area consuntivi -->.
