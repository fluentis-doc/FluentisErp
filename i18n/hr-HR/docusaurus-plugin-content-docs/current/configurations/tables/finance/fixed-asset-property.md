Ova tablica omogućuje definiranje jednostavne šifre i opisa svojstva koje se dodjeljuje pojedinim osnovnim sredstvima. Svojstvo se može koristiti kao kriterij za filtriranje pri pretraživanju ili ispisu, kako bi se dobio popis osnovnih sredstava s određenim svojstvom ili karakteristikom.

#### Posebna polja

**Opis**: opis svojstva osnovnog sredstva.
