title: Vrste napretka radova
sidebar_position: 14

Ova tablica dostupna je putem **Tablice > Upravljanje projektima > Vrste napretka radova** i sadrži dostupne tipove stanja napretka radova. Moguće je kreirati, pretraživati i brisati tipove. Svaki je definiran **Šifrom**, **Opisom** i **Numeracijom**.
